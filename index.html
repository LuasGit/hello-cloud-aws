01 / Primero lo importante

¿Qué es la computación en la nube?

Es acceder bajo demanda a recursos informáticos a través de una red, sin tener que comprar y administrar toda la infraestructura física por tu cuenta.

Antes, para publicar una aplicación necesitabas un servidor propio, electricidad, conexión, mantenimiento y seguridad física. Con la nube puedes aprovisionar recursos en minutos y administrarlos de forma remota.

¿Y qué es AWS?

Amazon Web Services es una plataforma que ofrece servicios de computación, almacenamiento, redes, bases de datos y mucho más.

↗

Escalabilidad

Aumentar o reducir recursos según la demanda de la aplicación.

◷

Bajo demanda

Crear recursos cuando se necesitan y dejar de usarlos cuando ya no hacen falta.

◎

Alcance global

Desplegar servicios en distintas regiones y acercarlos a tus usuarios.

02 / El ecosistema

Seis servicios AWS para empezar.

AWS tiene muchos servicios. Estos seis son una buena puerta de entrada para entender cómo se construye una aplicación real.

▣
01

EC2 · Cómputo

Máquinas virtuales donde puedes instalar Linux y ejecutar aplicaciones o servidores web.

▤
02

S3 · Almacenamiento

Almacena objetos como imágenes, documentos, archivos y respaldos.

♙
03

IAM · Identidad

Define quién puede acceder a AWS y qué acciones tiene permitido realizar.

λ
04

Lambda · Funciones

Ejecuta código por eventos sin administrar directamente un servidor.

▥
05

RDS · Bases de datos

Servicio administrado para motores de bases de datos relacionales.

⌁
06

VPC · Redes

Crea redes virtuales y controla la conectividad entre tus recursos.
